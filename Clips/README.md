# Example clips (synthetic)

**The recording annotations used in the thesis are confidential (Magna Electronics) and are not included in
this repository.**

The folders here are synthetic examples generated by `scripts/make_synthetic_clips.py`. They follow the
structure of the real annotation files (one folder per clip, one JSON file with `metadata` and `prelabels`),
so the notebook and the web app can run end to end, but every identifier, position, timestamp and label
combination is randomly generated. They describe no real vehicle, driver, location or recording.

To generate more:

```bash
python scripts/make_synthetic_clips.py --clips 50 --rows 200
```
